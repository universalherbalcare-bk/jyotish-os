$ ironclaw config set --help
Set a single configuration value by dot-separated key, routed through the alias table to its destination (config.toml, the encrypted secret store, or the WebChat v2 token file)

Usage: ironclaw config set [OPTIONS] <KEY> [VALUE]

Arguments:
  <KEY>    Dot-separated config key (e.g. google.client_id, openai.api_key, webui.token)
  [VALUE]  Value to set for non-secret keys. Secret-destination keys (`<provider>.api_key`, `google.client_secret`) reject positional values and always prompt with input hidden

Options:
      --rotate  `webui.token` only: rotate the WebChat v2 bearer token. Invalidates every existing browser session (the token doubles as the session-signing key)
  -h, --help    Print help
exit=0

$ ironclaw ironhub install --help
Install an IronHub tool or skill into Reborn state

Usage: ironclaw ironhub install [OPTIONS] <NAME>

Arguments:
  <NAME>
          Tool or skill name

Options:
      --confirm-host-access
          Confirm trusted-laptop host filesystem access for local-dev-yolo

      --kind <KIND>
          Disambiguate when a name exists as both a tool and a skill
          
          [possible values: tool, skill]

      --force
          Replace an existing registry package

      --acknowledge-unverified
          Acknowledge installing unverified community content

      --expected-version <EXPECTED_VERSION>
          Require the catalog entry to still have this version

      --expected-artifact-digest <EXPECTED_ARTIFACT_DIGEST>
          Require the catalog entry to still have this signed artifact digest

      --private-manifest-url-file <PATH>
          Install from an org-scoped signed manifest URL read from this file.
          
          Reading the URL from a file keeps its access token out of argv and shell history.

      --json
          Output the response as JSON

  -h, --help
          Print help (see a summary with '-h')
exit=0
