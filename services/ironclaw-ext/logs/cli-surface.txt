  completion  Generate shell completion scripts

  extension   Manage local Reborn extension lifecycle

  help        Print this message or the help of the given subcommand(s)

  -V, --version  Print version

$ ironclaw onboard --help
Initialize the standalone Reborn home and first-run setup marker

Usage: ironclaw onboard [OPTIONS]

Options:
      --force
          Overwrite generated config.toml, providers.json, and the completion marker

      --dry-run
          Show what would be initialized without writing files

      --import-history
          Reserve the history-import step in the onboarding summary.
          
          History import is not wired in this slice; the flag makes the missing step explicit without touching v1 setup/import state.

      --no-service
          Skip installing/starting the OS service (launchd/systemd) at the end of onboarding. Always effectively on in a non-interactive session (headless CI, a piped/scripted invocation) regardless of this flag — see `execute()`'s service step

  -h, --help
          Print help (see a summary with '-h')
exit=0

$ ironclaw serve --help
Start the Reborn WebUI service

Usage: ironclaw serve [OPTIONS]

Options:
      --host <HOST>          Host interface for the Reborn WebChat v2 HTTP listener. Overrides `[webui].listen_host` from the boot config file. Default (when neither is set) is `127.0.0.1`
      --port <PORT>          Port for the Reborn WebChat v2 HTTP listener. `0` lets the kernel pick a free port (useful for tests). Overrides `[webui].listen_port` from the boot config file. Default (when neither is set) is 3000

  -h, --help                 Print help
exit=0
